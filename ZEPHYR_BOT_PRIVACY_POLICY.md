# Zephyr Bot Privacy Policy

Zephyr is a Discord bot used for server moderation, support, tickets, role and access management, key generation, stock generation, community panels, and server utility features.

## Data We Process

Zephyr may process Discord data needed to provide bot features, including user IDs, guild IDs, channel IDs, role IDs, message IDs, timestamps, command usage, ticket and support activity, moderation events, and limited message content in channels where moderation or support automation is enabled.

## How Data Is Used

Data is used only to operate bot features, including moderation, spam prevention, support routing, ticket management, role and access syncing, generated key management, cooldowns, staff review, and abuse prevention.

Zephyr does not sell user data, share user data with third parties for advertising, or use message content to train machine learning or AI models.

## Data Storage

Zephyr may store limited operational data such as guild settings, panel and message IDs, generated key records, cooldown records, moderation and support logs, and user-linked access or reward records. Stored data is used only for bot functionality, abuse prevention, moderation, support workflows, and server management.

Where practical, message-content-related records are minimized and retained only as long as needed for moderation and support operations.

## Data Deletion

Users may request deletion of their activity data by opening a support ticket in the Zephyr Discord server or contacting server staff or administrators. Staff can review requests and delete applicable user-linked bot data when deletion is appropriate.

## Contact

For privacy or data deletion requests, open a support ticket in the Zephyr Discord server.
